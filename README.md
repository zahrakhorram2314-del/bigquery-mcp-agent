# BigQuery MCP AI Agent with Gemini & Cloud Run

This project implements an AI Data Agent using **Google ADK**, **Gemini 1.5 Flash**, and **Model Context Protocol (MCP)** to query structured BigQuery datasets directly.

## Features
- Integrates Gemini with BigQuery via MCP Toolset.
- Uses NYC Citibike public dataset for real-time SQL analysis.
- Containerized and deployed on Google Cloud Run.
